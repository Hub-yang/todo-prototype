# 决策记录

为什么是现在这个样子。想推翻其中任何一条之前，先读这里的理由——多数条目是权衡的结果，
不是随手定的默认值。完整论证见 [`archive/2026-09-10-prototype-chain-visualizer-design.md`](archive/2026-09-10-prototype-chain-visualizer-design.md)。

## 立项依据：竞品的缺口

| 站点 | 形态 | 缺口 |
|---|---|---|
| [Object Playground](http://www.objectplayground.com/) | 输入代码 → 真实运行 → 自动画对象图 | 2013 年的视觉与技术栈，无动画、无移动端、无分享导出 |
| [VisualizeJS](https://visualizejs.com/javascript) | 17 个 JS 概念的预设分步动画 | 不支持自定义代码；原型链只是一小节，深度不足 |
| [ProtoTree](https://weizmangal.com/ProtoTree/) | 真实运行时原型链渲染成可折叠树 | 只有树没有图，面向安全研究者而非教学 |
| [jsinheritance](https://github.com/rus0000/jsinheritance) | 静态 PNG 图解 + 文档 | 无交互 |
| [Molly's JS Object Hierarchy](http://www.mollypages.org/tutorials/js.mp) | 内置对象层次全景 | 年代久远，交互与视觉都很弱 |

**全网不存在「高颜值 + 可交互 + 支持自定义代码」三者兼备的原型链站点，中文领域完全空白。**

## 七条主决策（2026-09-10 头脑风暴结论）

1. **定位**：场景引擎为主 + 沙盒为辅，架构一次到位、交付分三期
2. **受众**：优先服务作者本人的博文输出，纯中文不做 i18n，分享与导图是一等公民
3. **场景范围**：A/B/C/D 四组全要，共 13 个——宁精勿多，13 个打磨到位胜过 40 个草草了事
4. **布局**：全屏画布 + 可折叠代码/讲解浮层。图是主体，D 组全景需要最大舞台，截图效果也最好
5. **视觉**：`aurora` 默认 + `neon` 可切换 + `paper` 仅导出；辉光只用于查找路径的聚焦瞬间
6. **交互深度**：播放 + 拖拽 + 探索式高亮，并为三期练习模式预留数据模型
7. **渲染层**：Vue Flow（自研布局 + 自定义节点/边），不用它的自动布局与默认样式

裁判标准（所有取舍的最终依据）：**当「炫酷」与「看得懂」冲突时看得懂优先**，
但不是放弃炫酷，而是把炫酷压缩到关键瞬间。

## 几条容易被「顺手优化掉」的决策

- **主题锁定 2 个（+1 个导出主题）**。每加一个主题，都要在 13 个场景的所有步骤上重新目测可读性，
  验证成本是乘法关系。
- **流光只在 `traverse` 播放时开启，静止时是实线**。全屏持续爬行的虚线看久了眩晕，
  也会稀释关键时刻的注意力。
- **导出走 `paper` 主题离屏重渲，而不是截当前画面**。`html-to-image` 对 `backdrop-filter` 与
  `drop-shadow` 的还原本就不可靠，与其与之搏斗，不如导出一张本来就为白底博客设计的图。
- **一期不做 GIF**。GIF 编码产物数 MB、耗时数秒，色深还会毁掉渐变；博文实际需要的是一两张定格图。
  确需动图时二期评估录屏，优于自研编码。

## 分期边界

| 期次 | 内容 | 状态 |
|---|---|---|
| 一期 | 13 个场景 + 探索式高亮 + 双主题 + 分享深链 + PNG 导出 | 已完成，见 [`progress.md`](progress.md) |
| 二期 | 代码沙盒：用户输入任意 JS → `runtimeAdapter` → 同一套 `GraphState` | 未立项 |
| 三期 | 动手搭建练习：用户自己拖节点、连 `[[Prototype]]` 线，系统 diff 校验 | 未立项 |

**一期明确不做（YAGNI）**：用户账号、任何后端、i18n、GIF 导出、E2E/视觉回归、
移动端深度交互（手机降级为「可读、可缩放、只播放」——全屏拖拽画布在小屏上体验有限，硬做不划算）。

## 风险与现状

| 风险 | 当初的对策 | 现在怎么样了 |
|---|---|---|
| 主题后补导致大规模返工 | 第一天 token 化，组件禁止硬编码色值 | 有效，静态检查零硬编码色值 |
| 节点多时掉帧 | `backdrop-filter` 仅用于浮层；开启 `onlyRenderVisibleElements` | 有效，d2 放大时只渲染 5/16 个节点 |
| `html-to-image` 还原滤镜失真 | 导出走 `paper` 无滤镜主题离屏重渲 | 代码路径已验证；**文件落盘尚未本人确认**，见 progress.md |
| **场景内容讲错**（最致命） | 场景数据纳入自动化断言 | 有效，13 个场景各有断言 |
| d1/d2 的环形与高密度结构布局打结 | `layout()` 是独立纯函数，先用最难场景写测试再反推算法 | 部分残留，见 [`reviews/2026-09-11-一期走查.md`](reviews/2026-09-11-一期走查.md) |
| Vue Flow 1.x → 2.0 升级成本 | 画布交互集中在 `components/canvas/`，`core/` 零耦合 | 升级面仍被限制在一个目录内 |
